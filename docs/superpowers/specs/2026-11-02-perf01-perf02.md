# PERF-01 + PERF-02 Design

## Intent

Close the remaining performance findings without changing unrelated Agent behavior.

## PERF-01 — server-scoped SignalR console traffic

Live log/stdin `logLine` events must not be broadcast to every authenticated SignalR connection. A client opening a server console subscribes to that server's SignalR group only after the server ID is validated by `ServerRegistry`. The group name is deterministic and preserves the exact validated server ID. `LogTailService` and `LocalProcessService` publish `logLine` only to that server group.

The existing Web UI already creates a separate SignalR connection for the selected console. Both stdin and read-only log consoles must invoke `SubscribeConsole(serverId)` before receiving live output. Closing the WebSocket relies on SignalR's normal disconnect cleanup to remove group membership. The existing client-side server-ID filter stays as defense in depth.

`installProgress` is not part of PERF-01 and remains globally broadcast because the install dashboard is Agent-wide rather than tied to a registered server subscription.

## PERF-02 — bounded completed install jobs

`ServerInstaller` must retain active jobs regardless of age or count. Completed jobs are retained for at most 24 hours and, after TTL cleanup, at most the 100 newest completed jobs remain. Cleanup is deterministic and concurrency-safe.

Pruning runs when a job is started, when a job is queried, and after a job becomes finished. It must not run on every SteamCMD progress line. Removal uses `ConcurrentDictionary.TryRemove`, and retention decisions are based on snapshots copied while each job state's lock is held.

## Tests

- A SignalR contract fails while `logLine` still uses `Clients.All`, while `StatusHub.SubscribeConsole` does not join a per-server group, or while the read-only Web UI fails to subscribe before starting log tailing.
- A C# behavior check proves expired completed jobs are evicted, active jobs are never evicted, only the newest 100 non-expired completed jobs survive, and equal timestamps produce deterministic eviction results.
- Full Windows/Linux CI and Agent publish remain required before merge.

## Non-goals

- No architectural privilege split (ARCH-01).
- No redesign of install-progress subscriptions.
- No redesign of the existing one-tail-per-server lifecycle/ref-count semantics.
